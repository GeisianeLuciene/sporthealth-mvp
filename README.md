O **SportHealth** é um Minimum Viable Product (MVP) desenvolvido para otimizar o acompanhamento clínico e a prescrição de treinos em academias. Focado na usabilidade mobile para instrutores de salão, o sistema digitaliza prontuários e destaca restrições médicas, mitigando riscos de lesões e promovendo uma prática esportiva segura.

Este projeto está diretamente alinhado ao **ODS 3 (Saúde e Bem-estar)** da ONU, utilizando a tecnologia como agente de prevenção e inclusão na comunidade.

---

## ✨ Funcionalidades

- 🔍 **Busca Otimizada:** Localização rápida de alunos cadastrados diretamente pelo smartphone do instrutor.
- 🩺 **Prontuário Clínico Digital:** Visualização imediata de dados vitais, IMC e histórico físico do aluno.
- ⚠️ **Risk Tags (Acessibilidade):** Sistema visual de alto contraste e iconografia para mapeamento de riscos (ex: Hipertensão, Condromalácia). Permite leitura rápida e acessível.
- ⚡ **Filtro de Restrições:** Triagem ágil que lista imediatamente os alunos que necessitam de atenção clínica especial no salão.

## 🛠️ Tecnologias Utilizadas

**Front-end:**
- [Angular](https://angular.io/) (Framework SPA)

- [Supabase](https://supabase.com/) (BaaS, PostgreSQL e APIs)

**DevOps & Qualidade:**
- **GitHub Actions:** Pipeline de Integração Contínua (CI).
- **Karma/Jasmine:** Testes unitários e de integração.

## ⚙️ Engenharia de Software e Boas Práticas

Este repositório foi construído seguindo rigorosos padrões da engenharia de software:

- **Versionamento Semântico:** Histórico rastreável utilizando *Conventional Commits* e revisões por meio de *Pull Requests*.
- **Integração Contínua (CI):** Esteira automatizada no GitHub Actions configurada para validar instalação de dependências, build de produção e aprovação de testes a cada novo *push*.
- **Garantia de Qualidade (QA):** O projeto atingiu **85% de cobertura de testes** (Test Coverage), garantindo a estabilidade das lógicas de negócio.
- **Validação Empírica (UX/UI):** Interface refatorada com base em testes de usabilidade reais com profissionais de educação física (ajustes de *touch targets* e contrastes).
